# Third-party provenance and licenses

This wrapper is independently developed and MIT licensed. The browser engine is **Moli by Lexmount**, pinned to [v1.1.16](https://github.com/lexmount/moli/releases/tag/v1.1.16). engine-lock.json records official release URLs and archive/binary SHA-256. No affiliation or authorship of the upstream engine is claimed.

Original Moli LICENSE-APACHE, LICENSE-MIT, license-metadata.json and the additional licenses directory are retained beside each bundled platform binary, including the upstream Chromium BSD-3-Clause text and Selenium NOTICE. The source ZIP refers to the pinned downloads; the runtime ZIP includes original documents.

Exact Node dependencies are recorded in package-lock.json: official @modelcontextprotocol/sdk, zod, linkedom, turndown, turndown-plugin-gfm, ipaddr.js and playwright-core. Their original license/notice files and package metadata, including transitive dependencies, remain in runtime node_modules. Playwright Chromium browser binaries are not bundled. The disabled optional adapter can only use an explicitly selected existing executable.

Node, Python, Codex and the existing Jev plugin are not redistributed or claimed as our code. Website snapshots retain their original URL and are local evidence, not permission to republish source content. Public source/runtime packages exclude personal host configuration and fetched evidence.
