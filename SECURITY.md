# Security and privacy

Use selected trusted public sources. This beta has not received an independent security audit and does not provide a complete Windows filesystem sandbox. Process cleanup and the policy proxy are not substitutes for full operating-system isolation.

Do not add login/profile access, credentials or private-network origins. Website text is untrusted data. The local evidence directory contains original rendered DOM and extracted text, so review it before sharing anything. HTTPS requests may include JavaScript-originated actions inside allowed origins; the proxy does not inspect TLS methods.

For a suspected vulnerability, do not post credentials, private URLs or sensitive source data in a public issue. Use a repository's private vulnerability reporting channel if the maintainer has enabled it; otherwise ask for a private reporting route with only a minimal non-sensitive description. No private reporting channel is claimed to be configured before publication.

Disconnect by removing only this server/skill. Preserve unrelated Codex configuration and local evidence. Host configuration backups may contain sensitive settings and must not be uploaded.
